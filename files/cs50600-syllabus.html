01Course Description

This course takes you inside database systems, built up from first principles, in the order the problems actually arise. We start from why the world needs so many different data systems and how a system stacks up from SQL down to data storage. Then we visit how an SQL query is processed in the most naive way, how the data flows between hardware resources, then adding classic ideas designed to solve specific issues, such as indexes, better operators, optimizers, and materialized views. We visit the engines running today's analytics and finish at the research frontier where AI and databases meet.
