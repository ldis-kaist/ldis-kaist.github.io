## Motivation

Natural-language interfaces to databases still fail on complex, real-world queries; the interesting failures lie beyond what a single LLM call can fix.

## Goal

An umbrella project combining LLM agents, DB execution feedback, RAG/TAG, approximate query processing, and finetuning — identify where SOTA baselines break, then attack those bottlenecks with the right combination of techniques.
