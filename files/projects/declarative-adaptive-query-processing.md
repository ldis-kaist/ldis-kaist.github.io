title: Declarative & Adaptive Query Processing
status: Open
area: Pure DB

## Motivation

Decades of query processing techniques (1981-today) remain fragmented; no single system adapts its execution to each query instance to approach the performance an oracle would achieve.

## Goal

Instance-optimal (cloud) DB through adaptive execution: measure the gap between a baseline and a virtual instance-optimal method, close it with recent and novel adaptive techniques, unified in a declarative framework.
