status: Ongoing
area: DB4AI

## Motivation

AI agents can now write and revise code against execution feedback — can they act as autonomic researchers for database internals, and what infrastructure do they need to do so reliably?

## Goal

A testbed where AI agents generate physical query plans (implementing and connecting physical operators), run them, and self-revise from execution results and correctness tests — analyzing the gap against plans from existing database systems and distilling lessons into new optimizers.
