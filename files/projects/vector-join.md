area: DB4AI

## Motivation

Vector joins — finding all query-data vector pairs within a distance threshold — are fundamental to vector and vector-relational databases powering multimodal retrieval and semantic analytics, yet state-of-the-art methods suffer from redundant index traversals and excessive distance computations.

## Goal

A unified framework for fast approximate vector joins: soft work sharing that reuses traversal results across queries, a merged index over query and data vectors, and an adaptive hybrid search strategy robust to out-of-distribution queries (arXiv:2603.16360).
